# Core Values — Template

> 本文件用于从价值观层面起草 Constitution 的 Core Values 部分。
> 更新后把结论回填到 `constitution.md` 的 Core Values 一节。

## 候选价值清单

逐个评估以下（或自行补充）在人生中的重要程度（高/中/低）：

- Autonomy 自主
- Growth 成长
- Security 稳定
- Connection 联结
- Contribution 贡献
- Mastery 精通
- Freedom 自由
- Wealth 财富
- Health 健康
- Family 家庭
- Recognition 认可

## Claimed vs Revealed

对每个标为"高"的价值，写下：

- Claimed：我声称它重要。
- Revealed：哪些长期行为证明我确实重视它？

> AI 可以指出差距，但不得自行修改 Value。
