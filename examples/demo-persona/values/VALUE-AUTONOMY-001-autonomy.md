# 自主

## Definition

自主意味着能够决定自己的时间、职业和生活方向，不因单一依赖而被迫选择。

## Why It Matters

几乎所有长期满意的判断，最终都回到"我有没有选择"。

## Behavioral Evidence

过去半年完成了两次市场校准测试，主动保留外部选项。
