# 稳定

## Definition

稳定意味着收入和环境的可预期性，以及安全边际（应急储备）。

## Why It Matters

完全无法预期的人生无法支撑长期积累。

## Behavioral Evidence

保留 6 个月应急储备；两次决策优先考虑熟悉的组织环境。

## Contradictory Evidence

在评估换城市时把"稳定"排在"自主"之后考虑（DECISION-LIFE-001 后续复盘）。

## Conflicts

与 Autonomy 冲突。
