# Situation

候选城市生活成本更低、技术岗位密度更高；现城市有熟悉的圈子与住房。

# Facts

- 候选城市租金约为现城市 60%（调研样本 12 套房源）。
- 现公司允许远程办公，但需每季度到办公室一周。
- 搬家可逆（试住 3 个月）。

# Unknowns

- 候选城市的社群质量与生活方式适配度未知。
- 两地长期收入差异未知。

# Emotion

对熟悉环境有不舍；对新环境有期待与轻度焦虑。

# Interests

长期：选择权与生活成本结构优化；短期：不急于做不可逆动作。

# Objectives

在不损失职业选择权的前提下，验证候选城市是否适配。

# Options

- A. 2026 年底前直接搬家。
- B. 试住 3 个月再决定。
- C. 暂不搬。

# Trade-offs

- A：如果不适配，回迁成本高。
- B：成本约 3 个月租金，信息增量大。
- C：维持现状，但生活成本结构不优化。

# Relevant Principles

- PRINCIPLE-LIFE-001：可逆实验优先 → 偏向 B。

# Lens Analysis

## Machiavelli

候选城市岗位密度高 → 议价权上升；搬家本身不改变权力结构。

## Legalism

规则上：远程政策是书面可依赖的；房租与收入数字可验证。

## Stoicism

可控：试住安排、预算；不可控：社群是否合拍。

## Adler

"不舍"是否在回避改变？小幅试住可避免直接对抗这种情绪。

## Taoism

问题值得解决（生活成本与选择权长期相关），策略应轻量——试住。

# Decision

（2026-08-20，Human）：选项 B——先试住 3 个月，再做是否迁移的决定。

# Next Action

两周内预订试住房源并安排一次工作周线下出差，完成低成本验证。

# Prediction

- 30 天后：试住体验初评（社群、通勤、成本结构）。
- 90 天后：拿到足够信息决定迁移或回迁。
- 365 天后：对照生活成本与职业选择权变化。

# Final Judgment

Human（demo persona 2026-08-20）：用 3 个月低成本试住换取一年后的
决定质量，值得。
